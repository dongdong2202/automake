模拟咖啡机机身触控交互大屏，为到店顾客提供选配定制、实付扣款与出餐全过程。

在浏览器中访问 https://tinylab.store/simulator/kiosk/，系统自动完成终端与云端服务器的安全连接，并加载该设备专属的门店信息与当前可用库存：

顶部横条动态监测 Redis 物理料桶与耗材余量（水、咖啡豆、鲜奶、大纸杯、杯盖等），毫秒级感知原料动态。

1.3 选购商品与多维规格定制 (SKU 动态算价)

在商品橱窗中，点击任意商品（如“生椰拿铁”或“西瓜汁”）右下角的 选规格 按钮，唤起多维规格定制弹窗：

🔍 点击图片放大预览 图 1-3：SKU 多维规格与实时价格联动

1. 杯型与温度联动：切换“中杯”或“大杯”（+0.02元），选择“热饮”或“冷饮”（冷饮耗用冰块与特定杯材）。

2. 实时价格公式盒：弹窗底部实时呈现透明公式，例如：基础价 ￥0.01 + 规格增量 ￥0.02 = ￥0.03。

3. 加入购物车：点击“确认加入购物车”，系统自动打包所选规格并推入结算通道。

1.5 微信真实收银台 (Native 扫码与付款码刷卡)

点击右下角绿色的 去结算出餐 按钮，系统向微信直连商户发起统一统一下单，弹出官方收银台：

🔍 点击图片放大预览二维码 图 1-5：微信 Native 官方支付真实收银台

模式 A · 微信 Native 二维码扫码 (推荐)：使用任意测试手机打开微信“扫一扫”，直接对准屏幕中的二维码即可唤起支付面板，金额为 ￥0.01 ~ 0.20 元。

模式 B · 付款码被扫 (条码枪模式)：切换至“付款码支付”选项卡，输入微信付款条码数字（18位），由商户直接向微信服务器发起即时扣费。

毫秒级回调侦测：收银台内置高速轮询器，一旦微信异步通知到达，收银台秒级关闭，并无缝切入饮品制作流程。

REFUND 支持在活动订单卡片中点击“一键全额退款测试”，资金原路返回，库存安全回冲。

📞 常见问题与应急排错指引

Q: 微信扫码后提示“商户订单号重复”？

A: 每次点击“去结算”，系统均自动生成全新的纳秒级商户订单号；若反复扫码旧单，点击“清空购物车”重新加购结算即可生成新单。

Q: Kiosk 页面提示“设备未认证”或“离线”？

A: 点击页面右上角蓝色的“终端认证 (sn001)”按钮，即可即时完成与云端的 Token 认证与状态同步。

Q: 如何修改测试商品的基础售价？

A: 登录后台进入“全局菜单档案管理” ➔ “编辑商品”即可调整基准价格；或在“设备综合管理” ➔ “设备菜单定制”中针对当前设备设定差异化微调折扣。

Q: 微信付款后机器没有出餐动作？

A: 页面下方黑匣子日志可直接查看 MQTT 下发状态。若本地模拟器未开启 MQTT 消费，可访问 底层通信黑匣子 查看下发的出杯控制报文。
